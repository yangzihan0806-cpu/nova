Contribute this device

What happens: while this tab is open and you have pressed Start, this browser renders small Mandelbrot image tiles for TartanGrid jobs and sends the results back.

  • Only the reviewed mandelbrot_v1 template runs — no uploaded code.
  • Default is 1 slot (one background worker thread).
  • You can pause or disconnect at any time.
  • Closing this tab stops contributing. Unfinished tiles are reassigned to other devices.

Choose an identifier the team can use to associate your contributions with you (for example, an Andrew ID). It appears on the Contributions page and in CSV exports. Leave it blank to contribute without an owner label.

This browser saves a random device ID to group your contributions across visits. It uses no hardware fingerprint. Browser and native contributions have separate IDs; you can give them the same owner label.
